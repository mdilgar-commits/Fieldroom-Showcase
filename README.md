# Fieldroom Product Showcase

A static product introduction for Fieldroom, the construction room matrix prototype. The live website is published with GitHub Pages from this repository's `main` branch and root folder.

## Update the site

Fill in the settings at the top of `showcase.js`: team name and members, the demo video link (YouTube, Google Drive or Vimeo; it is embedded automatically), the published live-demo link, and midterm feedback. Sections with nothing filled in stay hidden. Page content is in `index.html`; images are in `assets/`.

## Publish

The repository is configured for GitHub Pages. Commits pushed to `main` update the public site.
