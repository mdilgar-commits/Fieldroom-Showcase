# Fieldroom Product Showcase

A static product introduction for Fieldroom, the construction room matrix prototype. The live website is published with GitHub Pages from this repository's `main` branch and root folder.

## Update the site

Edit `index.html`, `styles.css`, and `showcase.js`. Set the project repository, AI Studio app, and video URLs in `showcase.js`. Add team names, a recorded product demo, and verified midterm feedback to `index.html` before presenting the showcase.

## Publish

The repository is configured for GitHub Pages. Commits pushed to `main` update the public site.
